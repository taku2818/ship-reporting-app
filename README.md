# Ship Reporting App

音声入力による船舶報告アプリケーション。

## 概要

現場作業者が船舶に関する問題を音声で簡単に報告し、記録・管理するためのWebアプリケーションです。

## 機能

*   報告者、番船名の選択
*   音声入力による報告内容の記録
*   報告ログの表形式表示
*   各報告の削除機能
*   報告ログのCSVエクスポート機能

## ローカルでの実行方法

1.  このリポジトリのファイルをダウンロードします。
2.  `index.html` ファイルをWebブラウザで開きます。

## 動作環境

*   Web Speech APIをサポートする最新のWebブラウザ（Google Chrome推奨）。
*   マイクへのアクセス許可が必要です。

## デプロイ

このアプリケーションは静的サイトとして [Render](https://render.com/) にデプロイされています。
